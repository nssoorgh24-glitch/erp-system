التجهيز للعمل أونلاين من أي مكان

النسخة الحالية ما زالت تحفظ البيانات محليًا في المتصفح. هذه الشاشة توضح متطلبات الربط فقط؛ لا توجد قاعدة بيانات أو مزامنة سحابية مفعّلة حتى الآن.

  1. إنشاء مشروع قاعدة بيانات مركزية آمنة (Supabase/PostgreSQL).
  2. إنشاء حسابات دخول للمستخدمين وتحديد الشركة والصلاحيات.
  3. تشغيل ملف SQL المرفق لإنشاء الجداول وسياسات الحماية.
  4. رفع واجهة البرنامج إلى استضافة HTTPS وربط جميع الموديولات بواجهة قاعدة البيانات.
  5. تصدير نسخة JSON من البرنامج الحالي، ثم مراجعتها واستيرادها إلى قاعدة البيانات بعد اختبارها.
